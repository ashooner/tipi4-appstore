# Session

Session is a collaborative music practice and recording application. It provides multi-channel audio recording, song management with chord charts, and group sharing for bands and collaborators.

## Features

- **Multi-channel recording** — Record from multi-input audio interfaces with per-channel gain and labeling
- **Song management** — Organize songs with chord charts, lyrics, and metadata
- **Recording takes** — Capture, name, and annotate recording takes per song
- **Group collaboration** — Share recordings with bandmates and collaborators
- **Device profiles** — Save and reuse audio device configurations

# Blinko

Blinko is a self-hosted AI note-taking app built for fast capture, Markdown-based notes, and natural-language retrieval over your personal knowledge base.

This RunTipi package includes Blinko with a bundled Postgres database and persistent storage for both the application data and database.

- Privacy-focused self-hosted note management
- Fast capture with Markdown support
- AI-assisted search and retrieval
- Bundled Postgres service for a simple install

Some AI features may require configuring your preferred provider inside Blinko after installation.
